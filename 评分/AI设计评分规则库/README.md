# AI设计评分规则库

本目录是 AI 设计文档评分规则与评分报告模板的 SSOT，用于承接通用评分模型、报告输出格式，以及四类设计文档基线模板的模板特有评分规则。

## 文件说明

| 文件 | 说明 |
|---|---|

| [DFX评分规则.md](DFX评分规则.md) | 性能、可靠性、安全、兼容性、可维护性、可观测性 DFX 专项评分规则 |

## 维护规则

1. 通用评分模型、权重、等级、阻断项、维度评分细则维护在 [评分规则体系-v2.md](评分规则体系-v2.md)。阶段评分规则不得复制通用模型正文。
2. DFX 专项触发、证据、评分和阻断口径只维护在 [DFX评分规则.md](DFX评分规则.md)，阶段评分规则只能引用和说明阶段适配，不得复制六类细则。
3. 评分报告格式只维护在 [评分报告输出模板.md](评分报告输出模板.md)，不得复制到模板评分规则文件。
4. 模板评分规则文件只能维护模板特有差异，包括规则元信息、必须证据与模板章节映射、阶段特有维度评分细则、阶段对象级阻断项、阶段触发项检查表、常见扣分点和评分注意事项。
5. 四类模板评分规则引用 [repo/评分/设计文档基线模板/](../设计文档基线模板/) 下的基线模板，不重新定义模板正文。
6. 不适用章节应填写 `N/A` 并说明理由，不得删除。
