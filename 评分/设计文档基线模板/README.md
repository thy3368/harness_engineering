# 设计文档基线模板

本目录维护团队级四类设计文档基线模板：

| 文档类型 | 模板文件 |
|---|---|
| 技术预分析文档 | [技术预分析文档模板.md](技术预分析文档模板.md) |
| 架构设计说明书 | [架构设计说明书模板.md](架构设计说明书模板.md) |
| 概要设计说明书 | [概要设计说明书模板.md](概要设计说明书模板.md) |
| 详细设计说明书 | [详细设计说明书模板.md](详细设计说明书模板.md) |

## 使用规则

1. 评分前必须先确认文档对象和适用模板版本。
2. 未声明 PDU 派生模板时，按本目录团队基线模板评分。
3. 声明 PDU 派生模板时，按派生模板评分，但派生模板必须保留基线模板的评分必填章节，或在“偏离基线模板说明”中提供替代证据位置。
4. 四类模板中的“设计规则引用”“Checklist 自检记录”“AI评审结果记录”“偏离基线模板说明”是公共必填区。
5. 不适用的章节不能删除，应填写 `N/A` 并说明理由。
