## 模块二：S/A 级需求 WBS（关键点、难点、阶段性进展）

> 本模块只列 **S 级和 A 级**需求，逐项展开 WBS。让管理层一眼看清：每个高难度需求的关键点是什么、当前推进到哪一步。

**2.1 S/A 级需求 WBS 清单**

| 需求编号 | 需求名称 | 难度等级（S/A） | 关键点（业务/技术目标） | 难点（必须预先验证的） | 当前阶段性进展 | 下阶段动作（双周内） | 计划完成时间 | 风险 |
| -------- | -------- | --------------- | ----------------------- | ---------------------- | -------------- | -------------------- | ------------ | ---- |
| RP1.8-物料中心 | 物料中心 | S | 插件/物料包全生命周期，支撑 SEE 子系统交付 | MSE 替代 UFW、热加载、复合包校验、跨子系统引用 | 一阶段自测 60%；规范文档整改完成 | 5/29 提测；DFX/规格树/提测边界；交叉测试与产品验收 | 2026/05/29 | 资源不足；MSE 方案未明 |
| RP1.8-多应用部署 | 多应用部署编排 | S | 系统级变更编排，满足永安等客户 | UF30/PB2.0 协同；模版联调复杂度 | 变更查询/创建/模版联调；自测中 | 变更快照；实例绑定/解绑/删除 | 2026/05/31 部分提测 | 跨团队计划未对齐 |
| RP1.8-OpenAPI | OpenAPI 管控 | A | 统一 API 管控与商业授权 | 老 OpenAPI 下线；API 清单延期 | 管控+6 样例 API 发版；一阶段测试完成 | 授权页增强、API 粒度商业授权设计 | 待定 | 清单延期；增强设计未就绪 |

> 说明：
>
> - **难度等级定义**：**S级**：涉及核心架构变更/跨域；**A级**：单域架构调整；**B级**：模块级设计；**C级**：常规迭代。B/C 级需求不在本模块展开，仅汇总在模块四的合规检查中。
> - **关键点**：要做成什么（业务价值与技术目标）。
> - **难点**：为什么难（哪些能力/性能/兼容性是瓶颈）。难点必须能映射到模块三的预研动作。
> - **阶段性进展**：用动词+里程碑描述，例如"已完成原型验证 / 已输出概设 V0.5 / 主备切换通路已联调通过"。

> 填写要求：
>

> 3. "查资料 / 原型验证"也是合法的预研方式，关键是对结论与目标可达性给出明确判断。
