# CRES/UFT 规则知识库

## 目录结构

| 文件 | 内容 | 规则ID |
|------|------|--------|
| `01-syntax.md` | 伪代码语法速查：变量/赋值/条件/循环/SQL | PCS_001~005, FNC_001~003 |
| `02-macros.md` | 宏系统完整参考：系统宏+用户宏参数与用法 | SMAC_001~005, UMAC_001~009 |
| `03-mechanisms.md` | 核心机制：事务嵌套、加锁、M标记、while保护 | 机制级，无独立ID |
| `04-patterns.md` | 典型模式：服务流程、遍历、导出、撤单、成交 | 模式级，无独立ID |
| `05-naming-structure.md` | 命名规范+文件结构+数据类型 | SVC_001~002, NAME_001~003, DTY_001~002, ERR_001~003 |
| `06-dep-rules.md` | 数据导出保护规则 | DEP_001~005 |

## 加载指引

| 场景 | 必读 | 按需 |
|------|------|------|
| 分析/读取 CRES 文件 | `cres-expert.md`（已含核心检查点） | `02-macros.md` 宏详情 |
| 生成 CRES 代码 | `01-syntax.md` + `05-naming-structure.md` | `03-mechanisms.md` 事务加锁 |
| 批量处理逻辑 | `03-mechanisms.md` M标记部分 | `04-patterns.md` |
| 数据导出模块 | `06-dep-rules.md` | `04-patterns.md` 导出模式 |
| 撤单/成交场景 | `04-patterns.md` | `03-mechanisms.md` 加锁 |
