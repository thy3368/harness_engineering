# feature-tree 业务功能树专项规范模板

> 说明：本文件仅适用于“业务功能树”类型文档，且必须与 `General.md` 一起使用。

---

## 1. 基础信息

- 规范名称：业务功能树专项规范
- 适用文档类型：业务功能树
- 强制绑定：`standard/feature-tree.md`
- 更新方式：持续维护
- 当前版本：v0.1

---

## 2. 改造目标

请在此处补充，例如：

- 让功能层级清晰、完整、可检索
- 强化业务域、模块、功能点之间的层次关系
- 便于快速查看功能覆盖范围与边界

---

## 3. 推荐结构

推荐采用以下层级：

1. 业务域
2. 功能模块
3. 功能项
4. 子功能/操作点（如有）

可结合表格或树形列表呈现。

---

## 4. 重点检查项

| 检查项 | 是否必需 | 检查说明 | 修改建议 |
|---|---|---|---|
| 层级清晰 | 是 | 是否清楚区分模块、功能、子功能 | 统一层级 |
| 颗粒度一致 | 是 | 同层级内容是否粒度相近 | 拆分或合并 |
| 命名一致 | 是 | 同类功能命名是否统一 | 统一动宾结构或名词结构 |
| 边界明确 | 是 | 是否避免功能重复归类 | 调整归属 |
| 缺失项提示 | 否 | 是否需要标记待补充功能 | 增加待补充说明 |

---

## 5. 表达规范

- 优先使用树形结构、分级标题或表格
- 同层节点命名保持一致风格
- 尽量避免大段说明文字掩盖层级关系

---

## 6. 常见改造方向

- 将散乱列表重构为树形层级
- 合并重复功能点
- 将功能说明与功能名称分离展示
- 补充模块归属或业务域归类
