共9大系统，，每个系统的缺陷分析文档，见文末，共9份。综合分析情况如下：

# 一、结论摘要

本轮 9大系统 原始输入 19871 条，已导出 19672 条；状态审计中仍有 199 条需要续跑或人工确认。汇总口径只包含 9 个系统，不包含技术平台 LDP 对照样本。

*   G5（AI 语义评审）9128 条，占 46.4%，是 AI Code Review 的主要建设区域。
    
*   G6（运行测试）4301 条，占 21.9%，适合转化为 AI 辅助测试生成、集成测试和端到端测试补强，不宜直接算作纯 AI Code Review 覆盖。
    
*   G1-G4 共 1257 条，占 6.4%，更适合规则、构建、静态扫描、接口契约和 Schema 工具前置拦截。
    
*   G7-G8 共 321 条，占 1.6%，适合作为复杂执行场景和业务不变量专项能力。
    
*   G9 3352 条，占 17.0%，主要进入发布、制品、部署和环境门禁；G0 1313 条，占 6.7%，进入人工补资料池。
