# 通用文档编写规范检查点（AI校验版）
## 一、内容编写规范检查项
### 1. 结构规范
| 检查维度   | 检查点       | 校验规则                                                     | 是否强制 |
| ---------- | ------------ | ------------------------------------------------------------ | -------- |
| 标题层级   | 层级编号     | 全文使用1/1.1/1.1.1/1.1.1.1四级编号体系，无跳级、重复、冗余层级（超过四级） | 强制     |
| 标题逻辑   | 层级对应关系 | 一级标题为核心章节、二级为模块、三级为具体内容，同级内容平行无交叉 | 强制     |
| 标题完整性 | 空标题       | 所有标题下均有对应正文内容，无空标题                         | 强制     |
| 排版对齐   | 格式统一     | 所有标题左对齐，正文缩进一致；图表/列表紧跟对应标题，无悬空  | 强制     |

### 2. 语言规范
| 检查维度 | 检查点     | 校验规则                                                     | 是否强制 |
| -------- | ---------- | ------------------------------------------------------------ | -------- |
| 语言风格 | 书面化     | 无口语化表达、未解释的缩略语；语句通顺简洁，无超长/复杂句    | 强制     |
| 术语统一 | 术语一致性 | 同一术语全文表述一致（如“统一登录”不混用“单点登录”）         | 强制     |
| 术语解释 | 首次说明   | 专业术语/英文技术名词首次出现附带中文解释（例：OAuth2.0（开放授权）） | 强制     |
| 表述精准 | 无模糊词汇 | 无“大概”“可能”“差不多”等模糊表述；操作路径描述精准           | 强制     |
| 界面标注 | 按钮/菜单  | 操作按钮、菜单使用【】标注（例：点击【登录】按钮）           | 可选     |
| 步骤编写 | 有序罗列   | 操作步骤用阿拉伯数字有序编号，无关键环节省略                 | 强制     |
| 关键内容 | 精准标注   | 操作步骤、命令、参数精准无误，关键内容加粗标注               | 强制     |
| 异常提示 | 突出显示   | 异常场景、注意事项使用高亮/加粗等方式突出显示                | 可选     |

### 3. 图表规范
| 检查维度   | 检查点     | 校验规则                                                     | 是否强制 |
| ---------- | ---------- | ------------------------------------------------------------ | -------- |
| 架构图要素 | 完整性     | 架构图包含分层、箭头、说明、图例四要素                       | 可选     |
| 编号规则   | 图表编号   | 图编号：图+章节号+序号（例：图3-1 总体技术架构图）；表编号：表+章节号+序号（例：表4-1 核心技术能力清单） | 强制     |
| 排版要求   | 位置与间距 | 图/表紧跟对应文字描述，无悬空；与上下文保留适当间距          | 强制     |
| 图文一致   | 描述匹配   | 架构图内容必须与文字描述完全一致                             | 强制     |

### 4. 界面截图规范
| 检查维度 | 检查点     | 校验规则                                                     | 是否强制 |
| -------- | ---------- | ------------------------------------------------------------ | -------- |
| 截图质量 | 清晰度     | 截图清晰完整、无水印/遮挡，文字可辨、色彩正常                | 可选     |
| 标注规范 | 关键区域   | 关键区域用红色箭头/方框标注，样式统一                        | 可选     |
| 格式统一 | 尺寸与风格 | 截图尺寸统一、无拉伸变形，标注样式一致                       | 可选     |
| 配套性   | 步骤对应   | 每个操作步骤对应一张截图，复杂步骤分步配图                   | 可选     |
| 编号排版 | 标注与位置 | 截图标注编号（例：图 1-1 产品主界面），紧跟文字说明，全文连贯 | 可选     |

### 5. 技术规范

| -------- | -------- | ------------------------------------------------------------ | -------- |
| 版本号   | 精准度   | 版本号精确到具体数值（例：JDK17、SpringBoot3.5），无模糊版本表述 | 强制     |
| 性能指标 | 量化呈现 | 性能、容量等指标以数值量化（例：启动耗时≤3秒、并发支持10万+），无定性描述 | 强制     |

### 6. 特性价值规范

| -------- | ------------- | ------------------------------------------------------------ | -------- |
| 价值关联 | 业务/商业价值 | 每个技术点均对应价值描述，无仅描述功能的内容；价值方向符合“提升效率/降低成本/增强安全/支撑规模化” | 强制     |

### 8. 配置项说明规范

| ---------- | -------- | ------------------------------------------------------------ | -------- |

## 二、格式排版规范检查项
| 检查维度 | 检查点     | 校验规则                                                     | 是否强制 |
| -------- | ---------- | ------------------------------------------------------------ | -------- |
| 页面设置 | 适配性     | 按A4纸张适配（Markdown渲染默认适配）                         | 可选     |
| 标题格式 | 层级格式   | 一级：#1. 标题；二级：## X.X 标题；三级：### X.X.X 标题；四级：#### X.X.X.X 标题 | 强制     |
| 正文排版 | 分段与缩进 | 正文用两个空格换行分段；段落用&emsp;&emsp;缩进，段落间空1行  | 强制     |
| 表格规范 | 格式与样式 | 边框完整                                                     | 强制     |
| 高亮提示 | 标注方式   | 重要内容用**加粗**或<span style="background-color:yellow;">高亮</span>标注 | 强制     |
| 图片排版 | 位置与编号 | 图片与上下文空1行，编号居中置于图片下方（例：<center>图3-1 总体技术架构图</center>），尺寸适配页面 | 可选     |
| 版本控制 | 修订记录   | 标注版本号（V1.0等），用表格记录修订人、日期、变更内容       | 强制     |

## 三、AI校验补充规则
1. 所有检查项支持关键词/格式的正则匹配校验（如标题格式、保密标注、术语统一）；
2. 量化指标支持数值范围校验（如版本号、性能指标、环境配置数值）；
3. 结构性检查支持层级/序号的逻辑校验（如标题编号无跳级、步骤编号连续）；
4. 完整性检查支持字段/内容的缺失校验（如配置项表格字段无遗漏、接口异常场景无缺失）；
5. 一致性检查支持全文术语/配置项名称的重复校验（如同一术语多表述识别）。

## 四、AI 自动判定规则（精简版）
**AI 必须标记不合格的场景（只要违反任意一条）**

1. **标题跳级、空标题、无编号**
2. **术语不统一、出现模糊词**
3. **配置项表格缺字段**
4. **接口缺入参/出参/异常**
5. **步骤缺校验、缺编号**
6. **密码/密钥明文出现**
7. **版本号模糊（如 JDK最新版）**
8. **无文档版本号**
9. **图表无编号**
10. **操作步骤未按 1/2/3 结构化**
