# 产品运维手册规范检查点（AI检查版）
| 检查维度     | 检查子项           | 检查规则                                                     | 要求类型 |
| ------------ | ------------------ | ------------------------------------------------------------ | -------- |
| 总则合规性   | 编写目的           | 明确规范运维手册编写格式、内容结构等核心目标，覆盖全流程撰写口径 | 强制     |
| 总则合规性   | 适用范围           | 覆盖公司全品类产品、全部署/运维场景、全流程、全相关人员      | 强制     |
| 总则合规性   | 核心编写原则       | 完整包含可操作性、精准性、完整性、规范性、安全性、场景化6项原则，无缺项 | 强制     |
| 章节结构     | 修订记录页         | 包含修订日期、修订内容、修订人、审核人，格式统一且可追溯     | 强制     |
| 章节结构     | 前言（部署概述）   | 完整覆盖部署方案、资源要求、适用场景、业务容量、保障能力、部署差异、预计耗时、风险提示、前置要求9项内容<br/>按不同部署方案分别标注，量化表述 | 强制     |
| 章节结构     | 术语与缩略语说明   | 核心术语/缩略语（含端口、专有名词）表格化定义，无模糊解释    | 强制     |
| 章节结构     | 部署方案           | 按单机/集群/云端等方案拆分，每个方案包含环境要求、前置准备、部署步骤、配套表格4个子模块<br/>各方案结构一致，适配场景化要求 | 强制     |
| 章节结构     | 版本升级           | 覆盖升级前置准备、增量/全量/灰度升级步骤、升级后校验全模块   | 强制     |
| 章节结构     | 服务启动与校验     | 包含启停重启命令、状态查看、功能校验、日志路径，明确校验合格判定标准<br/>判定标准量化、无模糊表述 | 强制     |
| 章节结构     | 发布包说明         | 覆盖不同部署模式说明、物料清单、获取与校验3项内容            | 强制     |
| 章节结构     | 巡检规范           | 按核心链路/核心业务场景拆分，巡检表格包含场景、指标、工具、标准、异常处理等字段<br/>指标可量化，异常处理可执行 | 强制     |
| 章节结构     | 日常运维规范       | 覆盖开市/闭市/上线/下线运维及其他日常操作，清单化呈现<br/>明确时间节点、责任人、异常处置 | 强制     |
| 章节结构     | 应急&诊断规范      | 包含应急处置流程、常见故障诊断、应急联络清单，流程闭环<br/>故障诊断按“现象-原因-方案”格式梳理 | 强制     |
| 章节结构     | 环境迁移规范       | 按数据库/资产等场景拆分，包含前置准备、迁移步骤、回滚机制、校验内容 | 强制     |
| 章节结构     | 资源管理规范       | 覆盖密码、服务器、安装包、证书4类资源管理，每项含清单/存储/管控要求<br/>敏感资源标注【保密】，管控规则明确 | 强制     |
| 章节结构     | 常见部署故障与排查 | 覆盖高频故障场景，按“现象-报错-原因-方案-应急处理”格式梳理   | 强制     |
| 章节结构     | 附录               | 包含命令合集、配置模板、端口清单、下载地址、技术支持等核心内容 | 强制     |
| 章节结构     | 层级编号           | 部署方案按2.4.X、升级/巡检等按2.6-2.11层级，同级场景平行编号 | 强制     |
| 文字描述     | 术语统一           | 部署/升级/巡检等流程中“校验方法”“异常处理”等表述口径一致     | 强制     |
| 文字描述     | 场景化信息         | 开市/闭市/灰度升级等场景明确时间节点、触发条件、责任人       | 强制     |
| 图表规范     | 流程图             | 巡检链路、环境迁移数据/资产流向配套流程图，标注核心节点      | 可选     |
| 图表规范     | 表格编号           | 场景化表格按“表+章节号+序号”统一编号（如：表2.5-1）          | 强制     |
| 图表规范     | 界面截图           | 升级/巡检/应急处置关键步骤配套截图，标注核心按钮/指标        | 可选     |
| 联动配置检测 | 结构化呈现         | 按“检测前提-检测流程-检测项-补充要求”结构编写                | 强制     |
| 联动配置检测 | 检测项表格         | 字段固定，检测方法、合格标准、修复方案具体可执行             | 强制     |
| 联动配置检测 | 异常分级           | 巡检异常按轻微/中度/重度分级，对应不同处置优先级             | 强制     |
| 安全与保密   | 敏感信息处理       | 密钥/密码/内网IP等标注【保密】，用[敏感信息]占位，不明文展示 | 强制     |
| 安全与保密   | 权限管控           | 明确最小权限范围，避免过度授权                               | 强制     |
| 安全与保密   | 操作审计           | 重要操作记录操作人、时间、内容，明确日志路径                 | 强制     |
| 安全与保密   | 端口管控           | 仅开放必要端口，防火墙策略明确可查                           | 强制     |
| 安全与保密   | 敏感数据传输       | 环境迁移中敏感数据传输明确加密方式                           | 强制     |
| 场景化落地   | 部署方案适配性     | 每个部署方案独立成章节，内容适配场景，无通用化表述           | 强制     |
| 场景化落地   | 升级流程差异化     | 增量/全量/灰度升级操作差异明确，回滚机制具体                 | 强制     |
| 场景化落地   | 巡检指标量化       | 核心链路/交易巡检指标可量化、可检测<br/>无“正常/异常”等模糊判定 | 强制     |
| 场景化落地   | 日常运维清单化     | 开市/闭市等操作明确“做什么、谁来做、何时做、做错怎么办”      | 强制     |
| 格式规范     | 界面截图编号       | 按“图+章节号+场景序号”编号（如：图2.8.1-1）                  | 可选     |
| 格式规范     | 配置文件模板       | 附录中包含各部署方案配置模板，标注可自定义项                 | 可选     |
| 格式规范     | 错误码说明         | 按模块/场景分类，包含错误码、含义、触发场景、修复方案        | 可选     |
