# 产品最佳实践规范检查点（AI检查版）
| 检查维度   | 检查项                      | 检查规则                                                     | 类型 |
| ---------- | --------------------------- | ------------------------------------------------------------ | ---- |
| 基础结构   | 修订记录                    | 包含版本、日期、修订人、修订内容、审核人，版本号规范（如V1.0/V1.1） | 强制 |
| 基础结构   | 背景                        | 涵盖业务/技术背景（现状+约束）、可量化的客户典型问题（含问题类别、影响、频率） | 强制 |
| 基础结构   | 目标                        | 业务目标+技术目标（可量化）+验收标准，指标清晰可验收         | 强制 |
| 基础结构   | 影响范围                    | 覆盖功能/数据/部署/配置/第三方依赖范围，明确兼容性与风险点   | 强制 |
| 核心内容   | 解决方案-方案概述           | 一句话说明“做什么、改什么、达到什么效果”，配套架构图/流程图（如有） | 强制 |
| 核心内容   | 解决方案-适用条件与前置准备 | 明确产品版本、资源/权限要求、依赖组件、禁止条件              | 强制 |
| 核心内容   | 解决方案-操作/开发步骤      | 步骤可直接执行，一步一校验，包含操作内容、命令/代码、路径、校验方法、预期结果 | 强制 |
| 核心内容   | 解决方案-业务改造点         | 梳理流程/字段/调用改造点，明确影响业务、是否必须改造、替代方案 | 强制 |
| 核心内容   | 解决方案-注意事项           | 包含禁止操作、备份要求、灰度要求、回滚条件等风险提示         | 强制 |
| 核心内容   | 解决方案-对应配置           | 配置项、配置文件、推荐值、说明、是否热生效完整               | 可选 |
| 核心内容   | 解决方案-接口调整           | 接口、方法、入参/出参变更、兼容性说明完整                    | 可选 |
| 核心内容   | 解决方案-部署方案           | 部署模式、顺序、扩缩容策略、高可用保障清晰                   | 可选 |
| 验证与回滚 | 验证方案                    | 覆盖功能/性能/稳定性/监控验证，性能验证含指标、目标值、实测值、结论 | 可选 |
| 验证与回滚 | 回滚方案                    | 明确回滚触发条件、步骤、回滚后校验项                         | 可选 |
| 运维与支持 | 监控与运维                  | 核心监控指标、告警策略、日常运维项完整                       | 可选 |
| 运维与支持 | 常见问题与排查              | 包含问题现象、原因、解决方案、预防措施                       | 可选 |
| 附录       | 参考文档                    | 列出部署/接口/配置/运维手册等参考资料                        | 可选 |
| 附录       | 术语说明                    | 术语及对应说明清晰                                           | 可选 |
| 附录       | 错误码说明                  | 错误码、含义、处理方式完整                                   | 可选 |

### 补充说明
1. 所有量化指标（如TPS、响应时间、可用性）需明确数值，禁止模糊表述（如“性能提升”需改为“性能提升30%”）；
2. 操作步骤需保证“可直接执行”，命令/代码需附带路径、校验方法，确保不同人员执行结果一致。
