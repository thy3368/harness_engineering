# 开发手册编写规范检查点（AI检查版）
| 检查维度         | 检查项          | 检查规则                                                     | 是否强制 |
| ---------------- | --------------- | ------------------------------------------------------------ | -------- |
| 总则合规性       | 编写目的匹配度  | 手册编写目的是否贴合“规范开发指引、降低开发门槛、保障兼容性与稳定性”核心目标 | 强制     |
| 总则合规性       | 适用范围覆盖度  | 是否覆盖接口集成、系统配置、代码定制、功能扩展等二次开发场景，是否适配编写/审核/使用人员 | 强制     |
| 总则合规性       | 编写原则落地性  | 精准性：接口、配置、代码、步骤是否与产品实际逻辑一致，出入参/异常场景是否全覆盖<br>实用性：是否聚焦核心开发需求，提供可直接套用的内容<br>逻辑性：章节是否按“基础准备-集成配置-代码开发-接口调用-问题排查”排序<br>规范性：格式、术语、代码风格、命名是否统一<br>完整性：是否覆盖二次开发全流程，无关键信息遗漏 | 强制     |
| 章节结构完整性   | 修订记录页      | 是否按统一表格格式记录各版本修订日期、内容、修订人、审核人，确保版本可追溯 | 强制     |
| 章节结构完整性   | 前言（概述）    | 是否说明开发目的、适用场景、核心范围、阅读建议、环境要求、注意事项 | 强制     |
| 章节结构完整性   | 产品术语说明    | 是否梳理核心术语/专业词汇，按业务/技术分类，明确定义、用途、使用场景 | 强制     |
| 章节结构完整性   | 集成规范        | 是否覆盖不同集成场景的集成方式、步骤、注意事项，明确关键节点与校验标准 | 强制     |
| 章节结构完整性   | 整体介绍        | 是否说明产品开发架构、依赖工具及获取路径、核心能力、与周边系统关系 | 强制     |
| 章节结构完整性   | 快速开始手册    | 是否提供产品快速开发入门指引                                 | 强制     |
| 章节结构完整性   | 环境搭建说明    | 是否明确不同场景下的软硬件环境、配置步骤、环境校验方法       | 强制     |
| 章节结构完整性   | 开发指南        | 各功能模块是否包含功能说明、示例代码解析、配置项说明、接口说明 | 强制     |
| 章节结构完整性   | 常见问题（FAQ） | 是否整理高频集成/配置/代码/接口问题，明确现象、原因、解决方案 | 强制     |
| 章节结构完整性   | 调试与测试规范  | 是否说明调试方法、测试流程、测试标准，提供调试工具推荐、测试用例示例 | 强制     |
| 章节结构完整性   | 附录            | 是否包含依赖包地址、开发工具推荐、配置项/接口清单、技术支持方式等补充内容 | 强制     |
| 核心内容规范性   | 集成规范结构    | 是否按“集成场景-集成前提-集成步骤-集成校验-注意事项”编写：<br>场景：区分不同集成方式的适用场景<br>前提：明确环境配置、权限申请等准备工作<br>步骤：按顺序描述操作，关键步骤配截图/命令示例<br>校验：明确校验指标、步骤<br>注意事项：说明规避问题、异常处理、版本兼容、维护要求 | 强制     |
| 核心内容规范性   | 功能模块说明    | 功能说明是否明确解决的客户问题、代码实现逻辑、规格、前置条件 | 强制     |
| 核心内容规范性   | 示例代码解析    | 是否提供完整常用场景示例代码，配套功能、逻辑、参数、调用方法、修改注意事项解析 | 强制     |
| 核心内容规范性   | 配置项说明      | 是否梳理所有配置项，明确名称、路径、数据类型、赋值范围、默认值、说明、场景，及赋值错误的影响与修正方法 | 强制     |
| 核心内容规范性   | 接口说明        | 是否对应接口文档，明确适用场景、入参/出参、请求方式/地址、异常处理、调用示例 | 强制     |
| 审核与交付合规性 | 内容审核完成度  | 准确性：配置项、接口、代码是否与产品实际一致<br>完整性：是否覆盖核心/异常场景、依赖关系<br>结构化：核心信息是否符合固定格式<br>标准化：术语、命名、格式是否统一 | 强制     |
| 审核与交付合规性 | 版本关联        | 是否明确手册版本与产品版本的对应关系                         | 强制     |
| 优化项（可选）   | 内容可读性      | 示例代码是否添加注释，配置项/接口说明是否采用可视化表格，关键步骤是否配示意图 | 可选     |
| 优化项（可选）   | 拓展性          | 附录是否补充行业通用开发规范、跨平台适配建议等额外参考内容   | 可选     |
| 优化项（可选）   | 本地化适配      | 是否针对不同部署环境（如国产化系统）补充专属配置/集成说明    | 可选     |
