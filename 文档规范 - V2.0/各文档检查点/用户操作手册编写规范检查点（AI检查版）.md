# 用户操作手册编写规范检查点（AI检查版）
| 检查维度   | 检查项                 | 检查规则                                                     | 是否强制 |
| ---------- | ---------------------- | ------------------------------------------------------------ | -------- |
| 总则合规性 | 编写目的匹配度         | 手册编写需贴合“清晰易懂、格式统一、指引准确”核心目的，能支撑用户快速上手、降低使用门槛 | 强制     |
| 总则合规性 | 适用范围覆盖           | 需覆盖面向终端用户/管理员/运维人员的手册，包含界面展示、步骤指引等核心内容 | 强制     |
| 总则合规性 | 用语通俗易懂           | 用语直白简洁，无专业术语堆砌；术语首次出现标注释义，无口语化、模糊化表述 | 强制     |
| 总则合规性 | 图文并茂要求           | 关键操作、核心界面必须配图，图随文走，步骤与截图一一对应，无歧义 | 强制     |
| 总则合规性 | 内容准确完整           | 内容与产品实际功能/界面完全一致，无步骤遗漏、路径错误，覆盖常用功能与核心场景 | 强制     |
| 总则合规性 | 结构清晰性             | 章节层级分明、逻辑连贯，便于用户检索定位所需内容             | 强制     |
| 总则合规性 | 格式统一规范           | 全文格式、字体、编号、图标、术语保持统一                     | 强制     |
| 章节结构   | 修订记录页完整性       | 包含版本号、修订日期、修订内容、修订人、审核人等核心字段     | 强制     |
| 章节结构   | 前言（概述）完整性     | 涵盖产品用途、核心功能、适用用户、手册阅读建议、使用须知     | 强制     |
| 章节结构   | 产品术语说明           | 按业务模块分类，明确术语定义、用途及使用场景                 | 强制     |
| 章节结构   | 假定约束说明           | 明确文档适用范围、适用对象、环境/条件/数据等前提条件         | 强制     |
| 章节结构   | 产品总体介绍完整性     | 包含业务架构图+说明、整体界面说明、功能树、角色功能矩阵、整体流程与角色说明 | 强制     |
| 章节结构   | 功能模块操作指引完整性 | 按模块拆分，包含功能解决的客户问题、功能说明/规格、前置条件、操作入口、步骤（输入输出/业务规则/例外场景）、图示（含说明）、注意事项 | 强制     |
| 章节结构   | 版本兼容说明           | 说明功能支持的版本，可合入各功能模块注意事项（无版本兼容场景可省略） | 可选     |
| 章节结构   | 附录完整性             | 包含权限说明、快捷键、联系方式等核心附录内容                 | 强制     |
| 审核与交付 | 内容与产品一致性校验   | 核对手册内容与产品实际功能/界面一致，步骤、图文匹配无偏差    | 强制     |
| 审核与交付 | 格式排版校验           | 检查格式、编号、排版符合规范，无错别字、语病                 | 强制     |
| 格式规范   | 套用指定Markdown模板   | 优先套用《用户操作手册编写（V2.0）-模板》框架（无模板适配场景可自定义，但需满足格式统一要求） | 可选     |
