# 产品常见问题（FAQ）规范检查点（AI检查版）
| 检查维度 | 检查项               | 检查规则                                                     | 类型 |
| -------- | -------------------- | ------------------------------------------------------------ | ---- |
| 标题     | 问题标题精准性       | 禁止模糊描述（如“系统报错”“打不开”），需精准定位问题核心     | 强制 |
| 基础结构 | 问题概述             | 需用一句话说明问题现象及业务影响                             | 强制 |
| 基础结构 | 问题产生原因         | 需写明问题根因、触发条件，禁止仅描述表面现象                 | 可选 |
| 基础结构 | 发现版本与环境       | 明确填写版本范围、操作系统、部署模式等信息，禁止“可能”“大概”等模糊表述 | 可选 |
| 基础结构 | 影响范围             | 量化功能、用户、数据、业务、性能等影响范围及程度，无模糊表述 | 可选 |
| 基础结构 | 复现步骤             | 步骤可复现，清晰写明操作步骤及最终表象                       | 可选 |
| 基础结构 | 解决方案             | 需包含解决方案类型、可直接执行的详细操作步骤、完整命令/配置/SQL、效果验证 | 强制 |
| 基础结构 | 排查方式             | 提供排查顺序、具体排查命令，明确日志路径、关键字等排查信息   | 可选 |
| 基础结构 | 解决版本             | 若涉及版本，需明确升级版本及升级注意事项                     | 可选 |
| 基础结构 | 关联信息             | 按需填写关联问题、相关接口/配置、相关文档等信息              | 可选 |
| 内容规范 | 原因描述准确性       | 必须写明根因，禁止仅描述表面现象                             | 强制 |
| 内容规范 | 步骤可落地性         | 复现/解决步骤有序、无跳步漏步，每步可校验、可落地            | 强制 |
| 内容规范 | 解决方案可执行性     | 命令、配置、SQL可直接复制执行，无需额外理解，且必须放入代码块 | 强制 |
| 内容规范 | 环境/版本明确性      | 版本、环境信息明确，禁止“可能”“大概”等模糊表述               | 强制 |
| 内容规范 | 影响范围量化         | 需明确“部分/全部”“可继续/部分中断/完全不可用”等量化工况      | 强制 |
| 格式规范 | 命令/配置/SQL格式    | 所有命令、配置、SQL必须放入对应类型的代码块（bash/yaml/sql） | 强制 |
| 格式规范 | 同一类问题口径统一性 | 同类型问题描述、原因、解决方案等口径需保持一致               | 强制 |
| 补充信息 | 排查命令完整性       | 排查命令需完整、可执行，明确标注用途                         | 可选 |
| 补充信息 | 解决方案效果说明     | 需说明解决方案效果及验证结果                                 | 强制 |
| 补充信息 | 关联信息完整性       | 关联问题、接口/配置、文档等信息需准确、可追溯                | 可选 |
