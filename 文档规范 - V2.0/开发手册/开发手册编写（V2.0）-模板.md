#### 5.1.2 示例代码

java

```
// 编程语言标注：Java
import org.springframework.http.HttpEntity;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpMethod;
import org.springframework.http.ResponseEntity;
import org.springframework.web.client.RestTemplate;

public class UserInfoQuery {
    // 核心参数：接口地址（可修改为实际部署地址）
    private static final String API_URL = "http://localhost:8080/api/user/query";
    
    public static void main(String[] args) {
        // 1. 创建RestTemplate实例
        RestTemplate restTemplate = new RestTemplate();
        
        // 2. 设置请求头
        HttpHeaders headers = new HttpHeaders();
        headers.add("Content-Type", "application/json");
        headers.add("Authorization", "Bearer [替换为实际token]"); // 需替换为有效token
        
        // 3. 构造请求参数（可修改userId为目标用户ID）
        String requestParam = "{\"userId\":\"10001\"}";
        HttpEntity<String> requestEntity = new HttpEntity<>(requestParam, headers);
        
        // 4. 调用接口
        ResponseEntity<String> response = restTemplate.exchange(
            API_URL, 
            HttpMethod.POST, 
            requestEntity, 
            String.class
        );
        
        // 5. 输出响应结果
        System.out.println("接口响应结果：" + response.getBody());
    }
}
```

#### 5.1.3 代码解析

1. 核心逻辑：通过 RestTemplate 发起 POST 请求，调用用户信息查询接口，传入用户 ID 参数，获取并输出响应结果。
2. 关键参数：
   - **API_URL**：接口请求地址，需根据产品实际部署地址修改；
   - **Authorization**：请求头认证 token，需替换为有效凭证；
   - **userId**：请求参数中的用户 ID，需替换为目标用户 ID。
3. 调用方法：直接运行 main 方法，或集成至业务代码中调用。
4. 修改注意事项：1. token 需定期更新，避免过期；2. userId 需符合产品用户 ID 规则（数字，长度 8 位）；3. 异常场景需补充 try-catch 捕获。

#### 5.1.4 异常提示

|         异常现象          |        异常原因        |                       解决方案                        |
| :-----------------------: | :--------------------: | :---------------------------------------------------: |
| 接口返回 401 Unauthorized |   token 过期 / 无效    | 重新获取有效 token，更新请求头中的 Authorization 参数 |
| 接口返回 400 Bad Request  | userId 格式错误 / 缺失 |        检查 userId 格式，确保为 8 位数字且非空        |

###### 5.1.6.5.1 HTTP 请求示例

```
POST http://127.0.0.1:8080/api/user/query
Headers:
Content-Type: application/json
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIxMDAwMTAwMSJ9.xxx
Body:
{
  "userId": "10001001",
  "queryType": 1
```

###### 5.1.6.5.2 代码调用示例（Python）

```
import requests
import json

url = "http://127.0.0.1:8080/api/user/query"
headers = {
    "Content-Type": "application/json",
    "Authorization": "Bearer eyJhbGciOiJIUzI1NiJ9.eyJzdWIiOiIxMDAwMTAwMSJ9.xxx"
}
data = {
    "userId": "10001001",
    "queryType": 1
}
response = requests.post(url, headers=headers, data=json.dumps(data))
print("响应结果：", response.json())
```

##### 5.1.6.6 注意事项

1. 接口调用频率限制：单 IP 每分钟最多调用 60 次；
2. token 有效期为 2 小时，需定时刷新；
3. 查询全量信息（queryType=2）需管理员权限；
4. 接口返回数据需做脱敏处理（如手机号隐藏中间 4 位）。
