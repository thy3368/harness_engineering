#### 6.1.2 操作入口
[例：左侧功能菜单 → 【数据管理】→ 【数据查询】]

#### 6.1.3 操作步骤
1. 进入数据查询界面（图6-1），在【查询条件】区域设置筛选条件：
   - 【时间范围】：选择YYYY-MM-DD至YYYY-MM-DD；
   - 【数据类型】：勾选「XX类型」「XX类型」；
   - 【状态】：选择「已完成」；
2. 点击【查询】按钮，等待数据加载；
3. 如需导出结果，点击【导出】按钮，选择导出格式（Excel/PDF），保存至本地。

<center>图6-1 数据查询界面</center>

#### 6.1.4 注意事项
1. 时间范围最大支持查询近1年数据；
2. 导出数据量单次不超过10万条，超出需分批次查询；
3. 仅「数据查看权限」角色可执行此操作。

#### 6.1.5 增删改查规则
| 操作类型 | 规则说明                                               |
| -------- | ------------------------------------------------------ |
| 新增     | 本模块无新增操作                                       |
| 删除     | 本模块无删除操作                                       |
| 修改     | 本模块无修改操作                                       |
| 查询     | 查询条件支持模糊匹配；查询结果支持排序（点击表头字段） |

### 6.2 [功能模块2：如「用户管理」]
#### 6.2.1 功能说明
【解决客户问题】：

【功能说明】：说明模块价值，如「管理员可新增、编辑、禁用用户账号，配置用户角色权限」

【功能规格】：

【前置条件】：

#### 6.2.2 操作入口
[例：左侧功能菜单 → 【系统管理】→ 【用户管理】]

#### 6.2.3 操作步骤（新增用户）
1. 进入用户管理界面（图6-2），点击【新增用户】按钮，弹出新增表单；
2. 填写表单字段（表6-1），带*为必填项；
3. 点击【保存】按钮，验证字段格式无误后，完成新增。

<center>图6-2 用户管理界面（新增）</center>

表6-1 新增用户表单字段规则
| 字段名称 | 字段类型 | 长度 | 格式      | 必填 | 备注                  |
| -------- | -------- | ---- | --------- | ---- | --------------------- |
| 用户名   | 字符串   | 20   | 字母+数字 | 是   | 不可重复              |
| 姓名     | 字符串   | 10   | 中文/字母 | 是   | -                     |
| 手机号   | 字符串   | 11   | 11位数字  | 是   | 需验证格式            |
| 角色     | 下拉选择 | -    | -         | 是   | 可选：管理员/普通用户 |

#### 6.2.4 注意事项
1. 仅「系统管理员」角色可执行新增/删除/修改用户操作；
2. 禁用用户后，该账号将无法登录，数据不会被删除；
3. 修改用户角色后，需重新登录生效。

#### 6.2.5 增删改查规则
| 操作类型 | 规则说明                                             |
| -------- | ---------------------------------------------------- |
| 新增     | 必填字段：用户名、姓名、手机号、角色；用户名不可重复 |
| 删除     | 删除条件：用户无未完成的业务操作；删除后不可恢复     |
| 修改     | 可修改：姓名、手机号、角色；不可修改：用户名         |
| 查询     | 查询条件：用户名、姓名、手机号、角色；支持模糊查询   |
